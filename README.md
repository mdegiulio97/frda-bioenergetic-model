# frda-bioenergetic-model

Mechanistic models of Friedreich's ataxia (FRDA) at two scales, with identifiability analysis.

- **Cellular bioenergetics** (`pilot_L1_bioenergetic/`): a reduced ODE model with five states (Fe-S cluster pool, mitochondrial labile iron, ROS, NADH, NRF2 activity) driven by frataxin level. It reproduces the qualitative FRDA signature (lower ATP and aconitase activity, iron accumulation, higher ROS) and the direction of known interventions (NRF2 induction, NAD+ precursors). It is calibrated by least squares on fold-changes reported in published FRDA studies (PMIDs in `calibrate.py` and `fit_real_data.py`), with bootstrap uncertainty and profile likelihood for practical identifiability.
- **Cross-scale progression** (`L2_methodology_POC/l2cross/`): a differentiable JAX model of tissue damage and imaging/neurophysiology observables over time, with the cellular model as a per-patient input. It includes a synthetic data generator, MAP + Laplace inference, Fisher information / Cramér-Rao bounds, profile likelihood, and acquisition design by value of information. Three synthetic experiments (`experiments/e1_recovery.py`, `e2_voi.py`, `e3_misspec.py`) cover parameter recovery, acquisition design and robustness to model misspecification.

All data are either synthetic (generated by the code) or published summary values with their PMIDs; no patient-level data are used. Extracted from a private research repository; work under preparation is not included.

## Run

```bash
uv sync --extra dev
uv run pytest -q                                    # model invariants + L2 unit and smoke tests
uv run python pilot_L1_bioenergetic/run_pilot.py    # cellular-model figures
uv run python pilot_L1_bioenergetic/fit_real_data.py
uv run python pilot_L1_bioenergetic/uncertainty.py  # bootstrap + profile likelihood
cd L2_methodology_POC && uv run python -m l2cross.experiments.e1_recovery
```

The full test suite takes a few minutes on CPU.

## Limitations

- The cellular model is deliberately reduced: it is not the full Cortassa & Aon mitochondrial model (PMID 22057575), and several parameters are only weakly constrained by the available published readouts (see the profile-likelihood figure).
- Calibration targets come from different cell types and conditions; some are qualitative.
- The progression model is studied on synthetic data only.
- Fisher-information and Cramér-Rao computations involve near-singular matrices; results depend on numerical precision. JAX is pinned to the 0.10 series, the version the tests were developed with; with JAX 0.12 two Cramér-Rao tests fail.
- Not for clinical use.
